# AutoColor 重启方案设计：几何件级涂装与区域候选决策

## 目标
将 AutoColor 从“参考图逐面投影器”重构为“数字涂装辅助工具”。输入作者分件 STL 与 1~N 张参考图，输出件级连续 RGB 3MF，并对件内明显多色区域提出可解释候选。核心目标是颜色排序不翻转、不给模型错误染色、不因视角顺序覆盖已确认结果。

## 硬约束
- 不训练新的语义模型。
- 不把 SAM2、Depth Anything 或扩散模型作为主决策器；它们只能作为可选辅助。
- 不做顺序覆盖；所有自动结果先收集、后统一决策、一次应用。
- 不可靠的区域保持件级主色并进入旗帜列表，禁止静默猜色。
- 输出连续 RGB；色板映射留给切片软件，吸附只作可选 UI。
- 0.4mm 喷嘴下不可打印的微小色块不追求面级精度。

## 主链路
```text
导入分件 STL
→ 几何整理与件 ID 缓冲
→ 参考图卫生层与颜色区域证据
→ 件级颜色候选收集
→ Lab 截尾/主峰统计与跨视角统一决策
→ 件级颜色写入
→ 件内多色候选发现
→ 面邻接“按边缘”区域生长
→ 候选统一接受/旗帜/拒绝
→ 一次应用 face-level 结果
→ 连续 RGB 3MF 导出
```

## 数据模型
每个 part 保存：

```text
color/base_color: 当前件级颜色
confidence: 件级置信度
flagged/reason: 人工复核标记
face_candidates: 自动候选集合
face_overrides: 人工确认的面级颜色
```

每个候选区域保存：

```text
region_id
faces
color
source_views
support_pixels
confidence
edge_consistency
accepted
reason
```

自动重跑只更新自动候选和自动接受结果，不删除 `face_overrides`。

## 件级取色
- 使用 three.js 件 ID 缓冲决定某件在每个视角的真实可见像素。
- 参考图只提供颜色证据，不直接给每个三角面赋色。
- L0 卫生层标记欠曝、边框、水印和明显不可信像素；过曝亮部保留并钳制，交给主峰/截尾统计处理。
- 每件每视角：ID 掩码腐蚀 1~2px，使用 Lab 主峰或截尾中位色。
- 跨视角先收集，再以可见像素、受光质量、视角正面程度和颜色一致性统一决策。
- 输入视角顺序交换后，结果必须等价。

## 件内多色候选
- 以件级主色为基准，在每件可见像素中寻找稳定的颜色离群簇。
- 颜色差使用 Lab ΔE；候选需要满足最小颜色差、最小可见像素和最小连通面积。
- SAM2 只可作为参考图区域提议器，不直接写入模型颜色。
- 候选映射到面后，沿面邻接图执行“按边缘”区域生长：颜色差、二面角、曲率和几何间隙任一超过阈值即停止。
- 至少两个独立视角支持，或单一视角拥有足够大且连续的高置信区域，才允许自动接受。
- 低置信度区域只显示为候选/旗帜，不改变件级底色。

## 人工区域操作
第一版提供区域级操作而非逐面操作：
- 接受候选区域。
- 拒绝候选区域。
- 按边缘扩展。
- 按连通区域填充。
- 点击取色并应用到选中区域。
- 将区域标记为人工固定。

应用优先级固定为：

```text
件级 base_color
→ 自动接受 face_candidates
→ face_overrides
```

## 输出
- 分件使用对象级颜色和 extruder。
- 件内已接受区域使用 per-face paint。
- 3MF 的连续 RGB 颜色定义作为默认显示色；不强制吸附固定色板。
- 如果 per-face 编码验证失败，导出对象级件色并明确提示，不生成静默错误。

## 错误处理与回退
- 任何单视角采集失败，只降低相关候选置信度，不影响件级结果。
- 没有可靠件内候选时，完整回退件级纯色。
- 自动重跑不覆盖人工固定区域。
- 不同装配姿势或参考图中模型不存在对应几何时，显示“参考区域未映射”，不强行染到最近部件。

## 分阶段实施
### R1：稳定件级基线
保留并整理 STL 组合、件 ID 缓冲、L0/Lab 件级取色、连续 RGB 3MF、旗帜和 override；关闭旧顺序投影在主流程中的作用。

### R2：件内候选发现
实现件内颜色聚类、面邻接区域生长、先收集后决策和候选数据接口；先不接复杂 UI。

### R3：区域级交互
增加候选列表、按边缘/连通区域/点击取色操作，并将人工结果写入独立 override 层。

### R4：回归与格式验证
用洛茜和一个非标准分件样本验证颜色排序、顺序不变性、人工固定持久性、无椒盐噪点和 Bambu Studio 读取行为。

## 验收标准
- 重新排列参考图顺序，件级颜色和接受的面级候选等价。
- 自动重跑不覆盖人工 override。
- 一期件级结果不再出现整件黑色污染或顺序覆盖。
- 件内候选区域连续，无大面积椒盐噪点。
- 颜色证据不足时进入旗帜，不静默写错色。
- 参考图存在但模型没有对应几何时可明确提示。
- 连续 RGB 3MF 通过结构测试，并交 Bambu Studio 实测。
