# AutoColor 二期第一阶段设计：件内多色候选与全局决策

## 目标
在一期件级纯色结果之上，发现同一 STL 分件内部的明显多色区域，并将高置信度区域输出为 per-face 涂色。自动流程必须先收集所有视角候选，再统一决策；禁止按视角顺序覆盖已有结果。暂不训练新的语义模型，不把 SAM2 作为主决策器。

## 范围
- 输入仍为作者分件 STL + 1~N 张已上传渲染图。
- 使用一期的相机姿态、件 ID 缓冲、深度/可见性和件级主色。
- 对每个件、每个视角、每个可见面收集颜色候选。
- 在件内部做颜色聚类/色带峰值检测，发现明显偏离件主色的候选子区域。
- 跨视角按颜色稳定性、可见像素数、视角正面程度和遮挡情况统一接受或拒绝。
- 接受的子区域写入 face-level slots；未接受面继续使用件级主色。
- 保留人工点击/手动改色的持久 override 接口，但本阶段先实现数据层和基础候选展示。

不包含：新语义模型训练、通用语义命名、自动拆 STL、半透明物理材质重建、切片路径优化。

## 数据模型
每个 part 增加：

```text
base_color: 件级主色
face_candidates: face_index → {
  candidates: [{ rgb/lab, view_index, confidence, visible_pixels }],
  accepted: bool,
  accepted_color: RGB|null,
  source: "cluster"|"manual",
  reason
}
face_overrides: face_index → RGB  # 人工结果，优先级最高
```

会话级增加：

```text
phase2_status: idle|collecting|deciding|ready|failed
phase2_summary: { candidate_regions, accepted_faces, flagged_regions }
```

自动重跑只更新自动候选和自动接受结果，不删除 `face_overrides`。

## 数据流
1. 一期转台流程完成后，已有每视角姿态。
2. 对每个视角渲染件 ID 缓冲和深度缓冲；只在件 ID 对应的可见区域采样，不使用旧的逐面顺序覆盖循环。
3. 对每个件收集可见面的颜色样本：先做 L0 清洁、白平衡和邻域中值；按面保存候选，不立即修改 mesh 或导出数据。
4. 每个件以一期 `base_color` 为中心计算颜色差异，在 Lab 空间检测明显的第二/第三色带。候选须满足最小色差、最小连通面积和最小可见像素门槛。
5. 候选跨视角合并：颜色接近、面邻接连续且视角证据一致的候选归为同一子区域。
6. 统一决策：候选置信度由颜色差、跨视角支持度、可见像素、法向·视线和遮挡质量组成。高置信度候选接受；低置信度候选进入旗帜列表；没有稳定证据的候选保持件级主色。
7. 应用顺序固定为：`base_color` → 自动接受的 face candidates → `face_overrides`。任何自动重跑都不能覆盖人工 override。
8. 导出时只把 accepted faces 和 manual overrides 编码成 per-face paint；没有 face-level 结果的件仍使用对象级件色。

## 决策规则
- 单个视角出现、低于最小面积或与主色差异小的簇：拒绝，保留件级色。
- 至少两个独立视角支持，或一个视角拥有足够大且连续的高置信区域：允许接受。
- 颜色差异使用 Lab ΔE；不以 RGB 欧氏距离作为最终标准。
- 候选区域边界使用面邻接图做多数投票/连通性清理，避免孤立椒盐面。
- 视角顺序不参与结果；输入图片顺序交换后，自动结果应保持等价。
- 面级候选与件级主色冲突但证据不足时，优先件级主色并旗帜提示，不静默写入错误颜色。

## UI 第一阶段
- 件列表显示件级颜色、件级置信度和二期候选数量。
- 候选区域显示来源视角、代表色、支持面数和置信度。
- 提供“接受全部高置信度候选”“仅应用已接受候选”“清除自动候选”操作。
- 人工 override 单独显示“已固定”，自动重跑不改变它。
- 本阶段不做复杂语义名称；显示“候选区域 1/2/3”即可。

## 错误处理与回退
- 任意视角采集失败：跳过该视角并降低相关候选置信度，不影响一期件级结果。
- 聚类失败或候选不足：phase2 置 ready，接受面数为 0，保持件级纯色。
- per-face 3MF 编码失败：导出对象级件色，并在 UI 明确提示件内颜色未写出；不生成静默错误文件。
- 所有自动结果可一键清除，恢复到一期件级颜色。

## 验收标准
以洛茜包为回归样本：
- 重排输入视角顺序，接受的面集合和颜色等价。
- 自动流程不改变一期已正确的件级主色。
- 脸部/眼睛、尾巴尖、斗篷装饰、水晶等明显多色区域至少产生候选，不把低置信度区域直接涂入。
- 候选区域不出现连续大面积椒盐噪点；邻接平滑后孤立面显著减少。
- 人工 override 在重跑后保持不变。
- 无候选或失败时可完整回退一期件级纯色。
- 输出 3MF 的 per-face 编码先通过结构测试，再交由 Bambu Studio 实测确认。
