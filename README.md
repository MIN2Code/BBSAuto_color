# AutoColor — 白模自动分色

作者模型包（分件 STL + 渲染图）→ 组合 → 吸色 → 件级配色 → **多对象涂色 3MF**（Bambu/Orca/Snapmaker Orca 直接打开）。

## 用法

1. `run.bat` → http://127.0.0.1:8761/
2. 拖入全部分件 STL（保持世界坐标，自动组合装配）
3. 上传 1~N 张渲染图（自动剔背景、多图色板合并）
4. 「自动按件配色」——同前缀切件/左右对称件自动同色，件名语义匹配（hair/gem/boot/hood…）
5. 微调后「导出涂色 3MF」

## 已知限制

- 3MF 为文本 XML，超大模型（百万面级）文件体积大、切片器打开慢
- 涂色 3MF 的 extruder 分配格式需在 Bambu Studio 实测确认（首版）
- 渲染图吸色受光照/背景影响（已自动剔背景，多图合并互补）
