# AutoColor — 白模自动分色

作者模型包（分件 STL + 渲染图）→ 组合 → 吸色 → 件级配色 → **多对象涂色 3MF**（Bambu/Orca/Snapmaker Orca 直接打开）。

## 用法

1. `run.bat` → http://127.0.0.1:8761/
2. 拖入全部分件 STL（保持世界坐标，自动组合装配）
3. 上传 1~N 张渲染图（自动剔背景、多图色板合并；"该图方位角"填角色朝向可大幅改善转台拟合）
4. 「自动按件配色」——同前缀切件/左右对称件自动同色，件名语义匹配（hair/gem/boot/hood…）
5. 「转台取色（推荐）」——全局姿态拟合 + 件 ID 缓冲逐件取色，无投影串色、与视角顺序无关；旗帜件置顶待复核
6. 「发现件内颜色」（二期）——不拆件装饰/眼睛的件内多色候选：多视角面级证据 → 按边缘生长 → 统一裁决；摘要里点击行**只读预览**色块位置，再点取消
7. 微调后「导出涂色 3MF」

### 二期 API

- `POST /api/sessions/{sid}/phase2/collect`（body: `{"cameras": [...]}`，前端按钮自动携带）→ 候选收集与裁决，不改件色
- `GET /api/sessions/{sid}/phase2` → 状态/候选/旗帜摘要
- `POST /api/sessions/{sid}/phase2/apply` → 仅应用已接受区域与人工 face override 到 face_slots
- `DELETE /api/sessions/{sid}/phase2/auto` → 清自动候选，保留人工层

## 已知限制

- 3MF 为文本 XML，超大模型（百万面级）文件体积大（洛茜 56 件导出 322MB）、切片器打开慢
- 涂色 3MF 的 extruder 分配格式需在 Bambu Studio 实测确认
- 渲染图吸色受光照/背景影响（已自动剔背景，多图合并互补）
- **Bambu per-face paint 硬上限 16 耗材槽**：件内候选色超过 16 个时，超出的涂面在切片器里落到用户自选的耗材上；候选摘要圈选 ≤16 个区域再 apply 是预期工作流
- face_slots 为 uint8 槽编码（≤255 色），满后新区域色按 Lab 最近吸附
- 件内候选含光影梯度导致的过分割（区域级光影治理/合并为下一轮调优）；全件候选收集在百万面级模型上约 15 分钟
